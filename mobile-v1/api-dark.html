Hunch API

Read-only API to data from our resolved markets, pattern library, and leaderboards. Public & commercial tiers. Beta access by request.

What's available

Markets

All live and resolved markets, with category, resolution criterion, current price, volume, and outcome.

GET/v1/markets
GET/v1/markets/{id}
GET/v1/markets/{id}/history

Echoes

Full Echo metadata: title, kicker, summary, source list, linked pattern, linked markets, publish date, editor.

GET/v1/echoes
GET/v1/echoes/{slug}

Patterns

Pattern library: name, base rate, case bank summary, currently-active linked Echoes.

GET/v1/patterns
GET/v1/patterns/{slug}/cases

Leaderboard

Public rankings by Brier score, category, time window. Per-user public stats by handle.

GET/v1/leaderboard
GET/v1/users/{handle}/stats

Authentication

All requests authenticate via Bearer token in the Authorization header. Tokens issued from your account page.

Authorization: Bearer hk_live_xxxxxxxxxxxx

Rate limits

Rate limits enforced per token. Public tier: 100 req / 24h, no burst. Developer: 10,000 req / 24h with 100/min burst. Commercial: negotiated. Standard 429 response with Retry-After header on exhaust.

Get started

Beta access open by request. Write to api@byhunch.com with a paragraph on what you'd build. We respond within two working days.
