Accessibility

Accessibility statement

Hunch aims to meet WCAG 2.1 Level AA. We will know when we fall short of that and welcome feedback when we do.

WCAG 2.1 AA · target

Conformance

This site is designed to conform to WCAG 2.1 Level AA. We test on each design release using automated tooling (axe-core) and manual keyboard / screen-reader checks. Known issues are listed below.

What we have built for

  • Full keyboard navigation, including off-canvas menus and predict buttons
  • Visible focus rings on all interactive elements
  • Colour contrast meeting AA against the dark palette (text 4.5:1, large text 3:1)
  • Semantic HTML headings for screen-reader navigation
  • ALT text on all informational images; decorative SVGs marked aria-hidden
  • Forms labelled with explicit <label> tags and aria-describedby for error states
  • Skip-link to main content from every page (in progress)
  • Respect for prefers-reduced-motion for animations and transitions
  • Theme toggle: Light / Dark, with persistence (in progress)

Known issues we are working on

  • Date filter selects on Archive page do not announce changes to screen readers — fix in next sprint
  • Some Echo card hover-only colour shifts not yet duplicated as keyboard-focus styles
  • Light theme variants of several secondary pages pending

Compatibility

We test on:

  • Screen readers: VoiceOver (macOS, iOS), NVDA (Windows), TalkBack (Android)
  • Browsers: Safari, Chrome, Firefox, Edge — current and one previous version
  • Zoom up to 200% without horizontal scroll

Report an accessibility issue

If you encounter an accessibility barrier on hunch.uk, please tell us. We aim to respond within 48 hours.

Email: accessibility@byhunch.com
Please include: the page URL, what you were trying to do, what went wrong, and the assistive technology you were using.

Enforcement

If you contact us about an accessibility issue and are not satisfied with our response, you may contact the Equality and Human Rights Commission (EHRC) or, in Northern Ireland, the Equality Commission for Northern Ireland (ECNI).

Statement preparation

This statement was prepared on 5 June 2026 and is reviewed quarterly.
